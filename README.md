# Rohme Clipping

Turn live streams and videos into vertical Shorts, automatically.

Paste a YouTube, Twitch or Kick link, go live, or upload a video file. Rohme Clipping finds the best moments with AI (loudness + motion scoring), cuts them in sharp 2K, and uploads them to YouTube on schedule. You just play.

## Install

1. Download the Setup file and double-click it, then click Next a few times. Updating? Run the new Setup over your existing install — your clips, logins and settings are kept.
2. Your browser opens at `127.0.0.1:8899`. Paste a link and tap **Make clips**.
3. Optional: connect YouTube once in Settings → YouTube for auto-upload, and add a free Gemini API key in Settings → AI Gemini for AI-written titles.

## Features

- **AI picks the best moments** — loudness + motion scoring; only the best clips (score 85+) auto-upload.
- **2K Shorts, GPU-fast** — 1440×2560 vertical clips with NVIDIA NVENC, automatic CPU fallback.
- **Captions and hook title** — burned-in captions and a hook title card on every Short.
- **Facecam picture-in-picture** — Top, Bottom or Off, with a configurable facecam box that matches your OBS layout.
- **Long videos** — 16:9 long clips (3, 5 or 10 minutes, or a custom length).
- **Auto-upload on schedule** — posts to YouTube at peak slots (7 AM, 3 PM, 7 PM) with a pace limit.
- **Multi-channel and mirror** — up to 3 creators; best clips mirror automatically from one channel to another (Gaming → Reels).
- **Smart lists** — duplicate-live warning, clips grouped by live, global search, link history, Undo/Redo for deletes.
- **Customisation** — grid or list view, hide and reorder tabs, custom fonts, text styles, borders, animations, themes.
- **Update check** — the app tells you when a new version is ready.

## Requirements

- Windows 10 or 11 PC
- Internet connection
- Python, FFmpeg and yt-dlp — installed automatically on first run if missing
- Optional: a YouTube channel with a one-time Google Cloud OAuth setup, for auto-upload
- Optional: a free Gemini API key from Google AI Studio, for AI titles
