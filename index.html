Download and install

One file, a few clicks, and you are clipping.

Install

  1. Download the Setup file and double-click it, then click Next a few times. Updating? Run the new Setup over your existing install — your clips, logins and settings are kept.
  2. On the first run, Python, FFmpeg and yt-dlp install automatically if they are missing.
  3. Your browser opens at 127.0.0.1:8899. Paste a link and tap Make clips.
  4. Optional: connect YouTube once in Settings → YouTube for auto-upload, and add a free Gemini API key in Settings → AI Gemini for AI-written titles.

Requirements

  • Windows 10 or 11 PC
  • Internet connection
  • Python, FFmpeg and yt-dlp — installed automatically on first run if missing
  • Optional: a YouTube channel with a one-time Google Cloud OAuth setup, for auto-upload
  • Optional: a free Gemini API key from Google AI Studio, for AI titles
